### Техническое задание для AI-разработчика: Расширение функционала PPTX2PNG Bot

🤖 ## Контекст проекта и архитектурные ограничения
Ты дорабатываешь проект Telegram-бота на aiogram 3.x, который конвертирует файлы презентаций PPTX в PNG-картинки.
Перед написанием кода строго ознакомься с правилами архитектуры, зафиксированными в проекте:
Изоляция путей (SHM/RAM): Бот работает на Raspberry Pi. Все временные файлы обработки задач и логов (bot.log, debug.log) должны создаваться и обрабатываться строго в оперативной памяти внутри динамической директории SHM_DIR и LOG_DIR. Никогда не хардкодь локальные пути к постоянному диску!
Безопасность конфигурации: Файлы секретов (config.ini с токенами) и локальная база данных пользователей (allowed_users.txt, user_settings.json) находятся только локально на хосте. В коде запрещено использовать Path.cwd(). Все менеджеры должны инициализироваться относительно base_dir=Path(SCRIPT_DIR), чтобы разделять среды prod и test.
Персистентность настроек: Для управления параметрами пользователей используется класс UserManager (файл user_manager.py). Он мгновенно сохраняет любые изменения параметров в user_settings.json на диске и кастит строковые ключи JSON обратно в int для aiogram.



🎯 ### Твоя задача: Реализовать 3 новые функции в ветке dev
Необходимо последовательно спроектировать и написать код для следующих фич, не нарушая синтаксис и архитектуру инициализации путей.

## Задача №1. Выбор цветовой темы слайдов (Инверсия / Темная тема)
Интерфейс: Добавь в инлайн-клавиатуру настроек get_settings_keyboard(user_id) в bot.py новый ряд кнопок для выбора темы: Оригинал / Тёмная 🌙 / Светлая ☀️.
База данных: Расширь дефолтный конфиг пользователя в user_manager.py параметром "theme": "original" (значения: original, dark, light) и создай соответствующий callback-хендлер set_t_ для сохранения выбора в JSON.
Движок: Интегрируй этот параметр в обработку изображений слайдов (модули converter_engine.pyили convert.py). При выборе dark движок должен инвертировать цвета фона (например, через ImageOps.invert в Pillow), а при light — принудительно делать фон белым, сохраняя контраст текста.

## Задача №2. Интеллектуальный AI-редактор (Проверка орфографии текста)
Суть: Пользователи боятся опечаток на слайдах. Бот должен уметь извлекать текст и проверять его.
Реализация: Внедрить в процесс конвертации функцию парсинга текста из файла PPTX (с помощью python-pptx).
Логика работы: Извлеченный текст отправляется на проверку в локальный спеллер (pyspellchecker) или через внешнее API (Яндекс.Спеллер / OpenAI). Перед отправкой ZIP-архива с картинками бот должен прислать пользователю текстовый отчет, если на слайдах найдены подозрительные слова (Пример: "Слайд 4: возможно опечатка в слове 'Маркетинг'").

## Задача №3. Интеграция с внешними сетевыми хранилищами (Ссылки вместо файлов)
Суть: Большие презентации в 4K генерируют тяжелые ZIP-архивы, которые неудобно качать на мобильном интернете в Telegram.
Реализация: Добавить в настройки пользователя возможность переключения режима выдачи результата: В Telegram (ZIP) или В Облако (Ссылка).
Логика работы: Если выбран режим облака, бот должен загрузить готовый архив/картинки по протоколу WebDAV в Nextcloud, Яндекс.Диск или на приватный веб-сервер, а пользователю прислать красивую кнопку с короткой прямой ссылкой на скачивание.
